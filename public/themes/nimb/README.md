# Arte do tema Nimb

`guilda-hero.png` foi gerada para A Guilda VTT com a ferramenta integrada de geração de imagens. É uma ilustração original; as capturas do Fichas de Nimb serviram apenas para orientar a linguagem visual da interface, não foram fornecidas como alvo de edição nem usadas como pixels finais.

Prompt final: “Original wide fantasy tabletop illustration for A Guilda VTT: polyhedral dice, an unfurled parchment map, leatherbound field notes, candle and ancient stone architecture; panoramic 16:9 composition with dark warm negative space on the left for live UI text; hand-painted editorial fantasy, warm vermilion, amber, walnut and charcoal. No text, letters, logo, watermark, people or recognizable franchise marks.”

`attribute-frame.svg` é um ornamento vetorial original do projeto.

As fontes em `public/fonts/` vêm do repositório oficial [Google Fonts](https://github.com/google/fonts): Cinzel Decorative e Alegreya. Os arquivos `*-OFL.txt` guardam suas licenças SIL Open Font License 1.1.
