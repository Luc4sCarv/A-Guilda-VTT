# Instruções do projeto

- Use o skill/plugin **Ponytail** em toda tarefa de código deste projeto, no modo `full`, salvo pedido explícito do usuário por outro nível ou para desativá-lo.
- Prefira a menor solução que satisfaça o requisito atual: reutilize o que existe, use biblioteca padrão e recursos nativos antes de adicionar dependências ou abstrações.
- Não simplifique validação em fronteiras de confiança, proteção contra perda de dados, segurança ou acessibilidade básica.
- Não antecipe funcionalidades fora do MVP descrito em `VTT_Documentacao/`.
